# Backend – Registro de horas (Vappnet)

Microservicio REST con Spring Boot 3 (Java 17). Ver tabla de endpoints en el README principal.

    mvn spring-boot:run     # http://localhost:8080/api/health
    mvn test

Base de datos H2 en `backend/data/` (consola en `/h2-console`, JDBC `jdbc:h2:file:./data/registrohoras`, usuario `sa`).
